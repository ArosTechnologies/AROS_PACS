# AROS PACS - Database Dictionary

This dictionary defines the primary tables and their relationships in the PostgreSQL database, mapped directly from Django's Object-Relational Mapper (ORM).

## Core Models (`core.models`)

### `Study`
Represents a concrete radiological study, created once DICOM images have arrived from the PACS/RIS integration. Acts as a junction point between the Patient, Request, and Report.

| Field Name | Type | Description |
| :--- | :--- | :--- |
| `id_study` | `AutoField (PK)` | Primary Key. |
| `pacs_url` | `CharField` | URL to the DICOM viewer provided by Raditech. |
| `email_sent` | `BooleanField` | Tracks if the final results email was dispatched to the patient. |
| `date` | `DateField` | The date the study was performed. |
| `raditech_visit_id` | `CharField` | External integration identifier. |
| `accession_number` | `CharField` | External integration identifier. |
| `id_study_request` | `ForeignKey` | Relates to `assistantDashboard.StudyRequest` (CASCADE). |
| `id_report` | `ForeignKey` | Relates to `core.Report` (CASCADE, nullable). |
| `id_patient` | `ForeignKey` | Relates to `patientsDashboard.Patient` (CASCADE). |

### `Report`
Represents the medical diagnostic report generated by a Radiologist.

| Field Name | Type | Description |
| :--- | :--- | :--- |
| `id_report` | `AutoField (PK)` | Primary Key. |
| `status` | `CharField` | Lifecycle status (`PEN`=Pending, `PRO`=In Progress, `COM`=Completed). |
| `about` | `CharField` | Title/Subject of the report. |
| `patients_description` | `CharField` | Clinical indication or patient's symptom description. |
| `findings` | `TextField` | Radiologist's findings from the images. |
| `conclusions` | `TextField` | Final diagnostic conclusions. |
| `recommendations` | `TextField` | Medical recommendations. |
| `date` | `DateField` | Date the report was finalized (Defaults to now). |
| `doctor_in_charge` | `ForeignKey` | The radiologist who signed it (`doctorsDashboard.ReportingDoctor`). |


## Dashboard Models

### `patientsDashboard.Patient`
Profile for registered Patients receiving services.

| Field Name | Type | Description |
| :--- | :--- | :--- |
| `id_patient` | `AutoField (PK)` | Primary Key. |
| `user` | `OneToOneField` | Links to standard Django `auth.User`. |
| `profile_picture` | `ImageField` | Patient's avatar image. |
| `address`, `phone` | `CharField` | Contact demographics. |
| `gender` | `CharField` | `M` (Male), `F` (Female), `O` (Other). |
| `is_email_verified` | `BooleanField` | Verification flag. |
| `raditech_patient_id` | `CharField` | External integration identifier. |
| `mrn` | `CharField` | Medical Record Number (Unique). |
| `associated_doctors` | `ManyToManyField` | Privacy settings mapping which external `AssociateDoctor`s can view results. |

### `doctorsDashboard.ReportingDoctor`
Profile for the internal radiologists responsible for writing and signing diagnostic reports.

| Field Name | Type | Description |
| :--- | :--- | :--- |
| `id_doctor` | `AutoField (PK)` | Primary Key. |
| `user` | `OneToOneField` | Links to standard Django `auth.User`. |
| `profile_picture` | `ImageField` | Doctor's avatar. |
| `signature` | `ImageField` | PNG image of cryptographic/wet signature stamped onto PDF reports. |
| `gender`, `address`, `phone`| `CharField` | Demographics. |
| `university` | `CharField` | Medical school attended. |
| `professional_id` | `CharField` | Professional medical license number. |
| `specialty` | `CharField` | Medical specialty. |

### `associateDoctorDashboard.AssociateDoctor`
Profile for referring/external physicians who require access to their patients' results.

| Field Name | Type | Description |
| :--- | :--- | :--- |
| `id_associate_doctor` | `AutoField (PK)`| Primary Key. |
| `user` | `OneToOneField` | Links to standard Django `auth.User`. |
| `professional_id` | `CharField` | License number (Unique). |
| `is_verified` | `BooleanField` | Administrative verification flag (required for login). |
| *(Other fields)* | *Various* | Demographics and medical credentials similar to ReportingDoctor. |

### `assistantDashboard.Assistant` & `StudyRequest`
**Assistant:** Profile for front-desk staff.
**StudyRequest:** The initial request ticket created when a patient arrives.

| Field Name (`StudyRequest`) | Type | Description |
| :--- | :--- | :--- |
| `id_solicitud_estudio` | `AutoField (PK)` | Primary Key. |
| `diagnosis` | `CharField` | Preliminary diagnosis/reason for visit. |
| `requested_study` | `CharField` | Enumerated list of all supported radiological studies (e.g., 'Torax PA'). |
| `pdf_password` | `CharField` | 18-char random alphanumeric string used to secure the PDF. |
| `created_at` | `DateTimeField` | Timestamp. |
| `first_printed_at` | `DateTimeField` | Tracks when the physical ticket was first printed (12hr validity window). |
| `id_patient` | `ForeignKey` | The requesting Patient. |
| `id_associate_doctor` | `ForeignKey` | The referring Doctor (if applicable). |
