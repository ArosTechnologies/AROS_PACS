# Vibrant Cyan Design System

## Brand & Style
The brand personality is energetic, forward-thinking, and technologically advanced. By shifting to a "vibrant" color variant, the UI evokes a sense of digital precision and high-intensity innovation. The design style is **Corporate / Modern** with a lean toward **Minimalism**. It prioritizes clarity and high-action visibility through the use of luminous primary tones and a clean, Inter-based typographic scale.

## Colors
The color palette is anchored by a high-energy Cyan primary, supported by muted teal secondaries and a striking amber tertiary for high-contrast accents.
* **Primary (#00e7fd):** A luminous electric cyan used for primary actions and key brand moments.
* **Secondary (#477f88):** A sophisticated, muted teal-grey used for secondary UI elements and balanced integration.
* **Tertiary (#ffcb37):** A vibrant amber used for specialized highlights, warnings, or distinct interactive calls-to-action.
* **Neutral (#71787a):** A cool, balanced grey for text and structural elements to maintain a professional atmosphere.

## Typography
The system has transitioned to **Inter** for all typographic roles. Inter provides a highly legible, neutral, and modern "tech" feel.
* **Headlines:** Bold and clear (e.g., 32px for large headlines).
* **Body:** Optimized for readability with a 1.5x line height (e.g., 16px for large body text).
* **Labels:** Medium weights used for utility text to ensure functional elements remain distinct.

## Layout & Spacing
The layout follows a **Fluid Grid** system based on an 8px spacing rhythm.
* **Grid:** A 12-column system for desktop, collapsing to 4 columns on mobile.
* **Breakpoints:** Standard breakpoints at 600px and 1024px.
* **Margins/Gutters:** 24px margins and 16px gutters provide breathing room for the vibrant elements.

## Elevation & Depth
Depth is conveyed through **Tonal Layers** and **Ambient Shadows**.
* **Surface tiers:** Containers use subtle shifts in the neutral grey palette.
* **Shadows:** Low-opacity, diffused shadows tinted with #71787a.
* **Interaction:** Active states may use a subtle glow effect using the primary cyan color.

## Shapes
The design uses a **Soft** shape language (Roundedness: 1).
* **Standard radius:** 4px (0.25rem) for buttons and input fields.
* **Large radius:** 8px (0.5rem) for containers like cards and modals.

## Components
* **Buttons:** Primary buttons feature white text on a #00e7fd background.
* **Cards:** Minimalist cards with subtle borders or soft shadows.
* **Inputs:** 4px rounded corners with a vibrant cyan focus ring.
* **Chips:** Light tints of #477f88 for neutral categories or #ffcb37 for highlighted status indicators.
